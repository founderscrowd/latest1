HOW TO TEST
================================================================================

QUICK TEST (1 minute):
1. Verify you're admin: SELECT is_site_admin FROM profiles WHERE id = auth.uid();
   (If false: UPDATE profiles SET is_site_admin = true WHERE id = auth.uid();)
2. Run this SQL in Supabase:

DO $$
DECLARE
  admin_id uuid;
  user_id_var uuid;
  user_email_var text;
BEGIN
  SELECT id INTO admin_id FROM profiles WHERE is_site_admin = true LIMIT 1;
  SELECT au.id, au.email INTO user_id_var, user_email_var
  FROM auth.users au
  JOIN stripe_customers sc ON au.id = sc.user_id
  JOIN stripe_subscriptions ss ON sc.customer_id = ss.customer_id
  WHERE ss.status IN ('active', 'trialing') LIMIT 1;
  
  INSERT INTO notifications (type, title, message, data, recipient_id)
  VALUES ('subscription_activated', 'Test', 'User ' || user_email_var || ' subscribed.',
    jsonb_build_object('user_email', user_email_var), admin_id);
  RAISE NOTICE 'Notification created!';
END $$;

3. Check Profile → Notifications tab
   Should see notification appear within 1-5 seconds ✓

TRIGGER CONFIGURATION
================================================================================

Trigger Name:       on_subscription_activated
Table:              stripe_subscriptions
Events:             INSERT, UPDATE (status only)
Timing:             AFTER
Function:           notify_admins_of_new_subscription
Security:           DEFINER (runs as creator)

Activation Conditions:
- Status is 'active' or 'trialing'
- Not a duplicate notification (checked on UPDATE)
- At least one site admin exists
- stripe_customers record exists for user_id

Notification Created For:
- All users with profiles.is_site_admin = true

Data Included:
- user_id (UUID of subscribing user)
- user_email (Email from auth.users)
- customer_id (Stripe customer ID)
- subscription_id (Stripe subscription ID)
- price_id (Stripe price ID)
- status (Subscription status)
- current_period_start (Unix timestamp)
- current_period_end (Unix timestamp)
- activated_at (Notification creation time)
